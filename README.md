# Engenharia de Agentes de IA: fundamentos e prática

Livro didático em português, com teoria e prática a cada capítulo. O projeto do livro é um assistente de chamados de TI que cresce capítulo a capítulo e roda inteiro em Docker.

- Livro: [livro-engenharia-agentes-ia.md](livro-engenharia-agentes-ia.md)
- Código: [livro-agentes/codigo](livro-agentes/codigo) (copie `.env.exemplo` para `.env` antes de rodar)
- Saídas reais das execuções: `livro-agentes/saidas*`
